# Project Big Tester

**Project Big Tester** は、銀行・証券の資産情報、ポートフォリオ、資産推移、システム状態を統合し、AI支援とリスク管理を組み合わせてローカル環境で運用する個人向け資産管理・自動運用プラットフォームです。

本リポジトリは、実システムの構成・技術・安全設計を確認できる**サニタイズ済み技術公開版**です。生成されたデモではなく、実プロジェクトから公開可能な実装を選別しています。

> **公開方針**: 個人情報、実データ、認証情報、外部接続設定、銘柄選定・売買判断・配分・閾値・発注のロジックは含めません。

---

## 実際のProject Big Testerの機能

### 資産管理と可視化

- 銀行・証券の残高、保有状況、評価損益、資産推移をダッシュボードで統合表示します。
- ポートフォリオ、分析、監視、レポート、タイムラインを用途別の画面として提供します。
- 資産状態、システム状態、運用上のイベントを記録し、確認できる設計です。

### 自動運用の基盤

- 市場時間や処理状態に応じたスケジューラで、データ取得・状態更新・分析・レポート作成を実行します。
- 仮想取引と実運用の経路を分離し、運用モードを明示的に管理する設計です。
- 複数の時間軸・目的を持つ運用枠を扱い、資産保全を優先して状態を見直します。

### データとAI支援

- 市場・企業情報を取り込み、時系列データとして保存・参照する基盤を備えます。
- AIは市場コンテキストの分析、状態評価、事後レポートを補助します。
- AI応答だけに実行可否を委ねず、実行経路と分析経路を分離します。

### リスク管理と運用安全性

- 異常時に新規実行を抑止するキルスイッチと、状態を記録する監査設計を備えます。
- 生活資金を含む銀行残高は、運用判断の対象と区別して扱います。
- シークレットをソースコードに保存せず、実行時に安全な管理境界から取得します。
- 重要な状態変化やエラーを記録し、運用者が確認できるようにします。

具体的な戦略名、銘柄選定、シグナル、評価式、閾値、配分計算、注文処理、バックテスト結果は、戦略的優位性と安全性を守るため非公開です。

## 公開版に含まれる技術

### Frontend

- Next.js 16 / React 19 / TypeScript
- CSS ModulesとRechartsによるダッシュボードUI
- ポートフォリオ、分析、監視、レポート、タイムライン向けの画面実装
- サーバー側APIプロキシと、外部サービス接続を分離する境界

### Backend・データ基盤

- Python 3.11 / FastAPI / Pydantic
- SQLAlchemy 2.0によるDB接続とデータモデル設計
- SQLiteを用いたローカル開発、およびPostgreSQL / TimescaleDBを用いた時系列データ基盤
- 設定読込、サーバー側認可、レート制限、構造化ログ、コスト保護の共通コンポーネント

### インフラ・セキュリティ

- Windows、Podman、docker-composeを前提としたローカルコンテナ構成
- PostgreSQL / TimescaleDBの初期化と、localhost限定のポート公開
- AWS Systems Manager Parameter StoreとKMSを用いたシークレット分離の設計
- AI・通知・外部データ連携を、認証値をコードへ持ち込まずに扱う設計

## 公開版の構成

```text
.
├── frontend/                 # 実ダッシュボードとAPIプロキシ境界
├── backend/
│   ├── src/core/             # 設定、認可、レート制限、ログ、コスト保護
│   ├── src/models/           # DB接続と公開可能なAPIスキーマ
│   └── requirements.txt      # Backend依存関係
├── docker/postgres/          # DB初期化
├── docs/                     # 公開用アーキテクチャ資料
└── docker-compose.yml        # サニタイズ済みローカルインフラ構成
```

公開版からは、証券・銀行アダプタ、口座同期、発注、投資判断、バックテスト、最適化、AIプロンプト、実データ、内部運用資料を除外しています。

## 実システムと公開版の対応

| 実システムの領域 | 公開版で確認できるもの | 非公開のもの |
| --- | --- | --- |
| ダッシュボード | 実際の画面・コンポーネント・API境界 | 実口座データと接続先 |
| サービス基盤 | FastAPI起点、設定、認可、レート制限、ログ | 本番の運用配線と口座アダプタ |
| データ基盤 | DB接続、時系列DBのインフラ構成 | 実DBスキーマの詳細と実データ |
| AI支援 | 分離方針と公開可能なスキーマ | プロンプト、評価基準、判断内容 |
| 安全設計 | 安全方針、設定・認可・監査の基盤 | 発動条件、運用閾値、実運用履歴 |
| 投資判断 | 時間軸を分ける運用方針 | 選定・売買・配分・最適化のロジック |
